Kiến trúc hệ thống (đề xuất triển khai thật)

Bản demo này chỉ là giao diện. Dưới đây là cấu trúc để dựng thành SaaS thật.

🗄️ Supabase — Database & Auth

• Auth: Supabase Auth (email/password hoặc SSO công ty), lưu department_id và role (employee / manager / admin) trong bảng profiles, liên kết auth.users.id.
• Bảng chính: departments, employees (mã NV, họ tên, bộ phận, chức vụ, ngày vào làm, manager_id), leave_balances (theo năm), requests (type: gatepass/leave/attendance, status, payload JSONB, submitted_by, approver_id, approved_at), signatures (ảnh chữ ký lưu ở Storage, liên kết user).
• Row Level Security (RLS): nhân viên chỉ đọc/ghi đơn của chính mình; trưởng phòng đọc/duyệt đơn của nhân viên có manager_id = auth.uid(); admin toàn quyền — policy theo department_id.
• Realtime: dùng Supabase Realtime để trưởng phòng nhận thông báo ngay khi có đơn mới (subscribe bảng requests).
• Storage: bucket riêng cho chữ ký số & PDF đã xuất, quyền truy cập theo policy.

⚡ Cloudflare — Deploy

• Cloudflare Pages: host phần frontend (build tĩnh — React/Vue hoặc HTML như bản demo này).
• Cloudflare Workers: proxy/middleware cho các tác vụ cần chạy server-side (gửi email/thông báo duyệt đơn, sinh PDF phía server nếu cần bảo mật cao hơn client-side).
• Biến môi trường Supabase URL/anon key cấu hình qua Cloudflare Pages environment variables; không nhúng service_role key ở frontend.

🖨️ Sinh PDF theo mẫu ISO

Sau khi trưởng phòng duyệt, hệ thống lấy dữ liệu đơn (JSON) đổ vào template HTML giống 3 mẫu gốc (Giấy phép ra cổng / Đơn xin nghỉ phép / Phiếu xác nhận ngày công), chèn chữ ký số đã lưu, rồi xuất PDF (client-side bằng html2canvas + jsPDF như bản demo, hoặc server-side bằng Cloudflare Worker + thư viện PDF để bảo mật/định dạng tốt hơn khi in số lượng lớn).
